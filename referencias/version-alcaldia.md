# Versión para la Alcaldía de Zipaquirá

Fecha de publicación: 18 de noviembre de 2026. Código separado de la versión anterior. Portada: `docs/index.html`. Guía: `docs/guia.html`.

Lema solicitado: **Zipaquirá Cree, Protege y Avanza 2024-2028**. La denominación con 2028 figura en el artículo 1 del Acuerdo 02 de 2024 publicado por EPZ, página 6: https://epz.gov.co/wp/wp-content/uploads/2024/07/ACUERDO-02-COMPLETO.pdf#page=6 . Esta referencia comprueba el rótulo textual del PDM, no el período jurídico de mandato del alcalde.

El logotipo fue aportado por el usuario y se conserva proporcionalmente en `docs/assets/alcaldia-zipaquira.jpeg`. La interfaz está marcada como prototipo; no acredita adopción institucional.

Los registros de trabajo se guardan solo en el navegador con la clave propia `radar-alcaldia-zipaquira-trabajo-v1`. No se migran registros de otras versiones ni existe una base compartida entre equipos. La simulación está separada y no se guarda ni se exporta.

Este repositorio contiene únicamente la aplicación pública, cartografía de referencia, metadatos, plantilla vacía y pruebas. No contiene correos privados ni una base de delitos reales. No depende de una conexión con Facebook.
